# Algebraic Coefficient Generator (ACG)

**PyTorch implementation and benchmark suite for Algebraic Coefficient Generation of tensor-product B-splines with constrained tensor-train structure.**

This repository accompanies the work **"Algebraic Coefficient Generation for Learning Tensor-Product B-Splines with Constrained Tensor Trains."**

ACG keeps the classical tensor-product B-spline space unchanged and replaces the dense coefficient tensor by an implicit algebraic generator. Marginal B-spline basis functions are lifted into a finite-dimensional learnable $\Theta$-algebra, combined through ordered algebraic products, and mapped back to real spline coefficients through linear readouts.

> **Current scope.** The present paper and benchmark focus on static multivariate regression. Temporal ACG models and sequence architectures are deliberately left as future work and are described in the roadmap below.

---

## 1. Main idea

For each input coordinate $x_k$, ACG builds an algebra-valued spline lift

$$
Q_{r,k}(x_k)=\sum_{j=1}^{n_k} B_{k,j}(x_k)\,q_{r,k,j}.
$$

where $q_{r,k,j}\in\mathcal{H}_m(\Theta)=\mathbb{R}\oplus V$.

For $x=(a,u)$ and $y=(b,v)$, the learnable product is

$$

x *_\Theta y
=
\left(
ab-\langle u,v\rangle,\;
av+bu+\Theta(u,v)
\right).

$$

Here $\Theta:\Lambda^2 V\rightarrow V$ is alternating and bilinear.

One ACG path uses an ordered, parenthesized product

$$
L_{\Theta_{1:p-1}}(z_1,\ldots,z_p)
=
(\cdots((z_1*_{\Theta_1}z_2)*_{\Theta_2}z_3)\cdots)
*_{\Theta_{p-1}}z_p,
$$

followed by a real linear readout $\rho_r$. The predictor is

$$
\widehat f(x)
=
\alpha_0+
\sum_{r=1}^{R}
\rho_r\!\left(
L_{\Theta_{1:p-1}}
(Q_{r,1}(x_1),\ldots,Q_{r,p}(x_p))
\right).
$$

Because the product is multilinear, the resulting function remains **exactly inside the prescribed tensor-product B-spline space**.

---

## 2. Structural interpretation

ACG can be viewed as a structured coefficient generator between CP and generic Tensor Train parameterizations.

- **CP is a submodel of ACG.** Restricting all algebraic lifts to the scalar axis recovers ordinary CP spline factors.
- **One ACG path can have CP rank $m$.**
- **Each ACG path is an exact constrained Tensor Train** with TT ranks at most $m$.
- With $R$ paths, TT ranks are bounded by $Rm$.
- Interior TT slices are not arbitrary $m\times m$ matrices: they belong to the $m$-dimensional family generated by right multiplication in the $\Theta$-algebra.
- With sufficiently many paths, ACG can recover the complete tensor-product spline coefficient space.

The goal is therefore not to create a tensor class larger than generic TT, but to introduce an **algebraically structured inductive bias** for learning spline coefficients.

## 4. Optimization variants

The notebook studies several ways of learning the same ACG architecture.

### ACG-BCD-Ball

The main method uses cyclic block-coordinate descent.

- spline-lift blocks: regularized least-squares updates;
- readout blocks: regularized least-squares updates;
- depth-specific $\Theta_s$: projected-gradient updates;
- row constraint:

$$
\|\theta_a\|_2\leq 1.
$$

This is the main configuration reported in the paper.

### ACG-GD-Free

A fully gradient-based alternative in which the algebraic parameters are optimized without the closed-ball constraint. This variant separates the effect of the architecture from the effect of block-coordinate optimization.

### ACG-SBG-Riemannian

A stochastic block-gradient variant using Riemannian optimization for constrained algebraic parameters. It is included as an alternative geometric optimization strategy and remains an important direction for further stabilization and scaling.

## 5. Benchmark

### Real regression data

The benchmark contains 13 real data sets:

`Abalone`, `California Housing`, `CPU Small`, `Diamonds`, `FIFA Wage`, `House8L`, `House Sales`, `Parkinsons`, `Protein`, `Pulsar`, `SGEMM GPU`, `Sulphur`, and `Wine Quality`.

Under the reported approximately parameter-matched protocol:

| Model | Mean rank | Mean NRMSE | Mean R² | Wins |
|---|---:|---:|---:|---:|
| **ACG-BCD-Ball** | **1.385** | **0.475** | **0.727** | **9** |
| CP spline | 2.231 | 0.523 | 0.680 | 3 |
| CatBoost | 3.385 | 0.591 | 0.611 | 0 |
| ResNet | 4.538 | 0.684 | 0.487 | 0 |
| Spline KAN | 4.692 | 0.746 | 0.409 | 1 |
| MLP | 5.769 | 0.774 | 0.374 | 0 |
| TT spline | 6.000 | 0.787 | 0.345 | 0 |

ACG obtains the lowest mean NRMSE and the best mean rank, while requiring more training time than the other implementations.

### Synthetic problems

Four controlled targets are included:

1. ACG-structured;
2. CP-structured;
3. TT-structured;
4. Friedman-1.

ACG-BCD-Ball obtains the lowest reported NRMSE on all four under the common experimental protocol. The ACG-structured target is intentionally matched to the proposed architecture and should not be interpreted as an unbiased test of general superiority.

A particularly important point is that **ACG is contained in a compatible generic TT class**. Consequently, differences against TT are estimator/regularization/optimization results, not evidence that ACG has a larger function class.

## 6. Structural ablations

The repository also studies:

- interaction order $p$;
- number of algebraic paths $R$;
- number of basis functions $n_k$;
- cubic B-splines vs Legendre and Fourier bases;
- learned $\Theta$ with ball constraint;
- learned unconstrained $\Theta$;
- fixed quaternion multiplication;
- zero alternating interaction $\Theta=0$.

The experiments suggest that the benefit does not come only from learning $\Theta$: a suitable fixed nontrivial algebra can also provide a strong inductive bias.

---

## 7. Current limitations

The current implementation fixes several choices that deserve stronger controls:

- natural input-variable ordering;
- left-comb multiplication tree;
- limited TT optimization controls;
- higher training cost of BCD;
- non-identifiability/gauge symmetries of the algebraic parameters;
- possible multiplicative state growth at large interaction depth.

Future static-model experiments will therefore study variable permutations, balanced multiplication trees, stronger TT/ALS baselines, faster block solvers, normalization, and improved geometric optimization.

# 8. Research roadmap

The current article intentionally treats **static regression only**. The next stage is to extend the same algebraic principle from interactions between variables to interactions **across time**.

## 8.1 Temporal ACG representation

For a multivariate time series

$$
X^t=(x_1^t,\ldots,x_d^t),
$$

each variable can first be lifted into the $\Theta$-algebra:

$$
z_k^t
=
\sum_j B_j(x_k^t)\,q_{k,j}.
$$

The complete observation at time $t$ is then represented by an algebraic state

$$
Z^t
=
z_1^t *_\Theta z_2^t *_\Theta \cdots *_\Theta z_d^t.
$$

This creates a compact state in which contemporaneous multivariate spline interactions are already encoded algebraically.

Temporal dependence can then be introduced directly in the same algebra. For example,

$$
Z^{t+1}
=
Z^t *_\Theta Z^{t-1} *_\Theta \cdots *_\Theta Z^{t-L+1},
$$

or, more generally, through learned lag-dependent products and readouts.

This gives a model in which **both cross-variable interactions and cross-time interactions are generated by the same algebraic mechanism**.

## 8.2 Lag-dependent and recurrent ACG

Several temporal variants will be studied:

- **ACG-Lag:** independent algebraic interactions for a finite lag window;
- **ACG-Recurrent:** a recurrent algebraic state updated through $*_\Theta$;
- **ACG-Shared-$\Theta$:** the same multiplication law is reused through time;
- **ACG-Lag-specific-$\Theta$:** different multiplication laws are learned for different lags;
- **ACG-Ball:** constrained $\Theta$ inside Euclidean balls for stability;
- **ACG-Free:** unconstrained $\Theta$;
- **Riemannian ACG:** geometric optimization of constrained algebra parameters.

An important question will be whether sharing $\Theta$ across time improves statistical efficiency or whether lag-specific algebras better capture nonstationary temporal interactions.

## 8.3 Algebraic temporal relations

The product

$$
Z^t *_\Theta Z^\tau
$$

can itself be interpreted as a learned algebraic relation between two observations.

This opens the possibility of defining:

- algebraic autocorrelation-like descriptors;
- lag interaction kernels;
- temporal similarity scores;
- higher-order lag interactions;
- algebraic state-space models;
- causal interaction paths.

Unlike a scalar correlation coefficient, the relation remains an $m$-dimensional algebraic object before readout.

## 8.4 ACG sequence models and $\Theta$-attention

A second research direction is to use ACG states inside sequence models.

### $\Theta$-Q

A single ACG stream produces algebraic query states $Q_t$. Standard similarity can be used for routing, while the message itself is algebraic:

$$
R_{t,s}=Q_t *_\Theta Q_s.
$$

The output aggregates causal algebraic relations rather than only scalar-weighted value vectors.

### $\Theta$-QK

Separate ACG maps generate $Q_t$ and $K_t$. Routing and algebraic relation construction can therefore use different learned spline-algebra representations.

### $\Theta$-QKV

Separate ACG maps generate $Q_t$, $K_t$, and $V_t$, combining conventional attention routing with $\Theta$-algebraic message/value interactions.

These models are deliberately outside the scope of the current regression paper.

## 8.5 Multiplication trees and temporal hierarchy

Because the learned algebra is not required to be associative, parenthesization is part of the architecture.

For temporal data we plan to compare:

- left-comb causal products;
- balanced trees;
- hierarchical/multiscale temporal trees;
- learned tree structures;
- recurrent shared products.

This may provide a natural way to encode short-, medium-, and long-range interactions without forcing all temporal dependencies into the same multiplication pattern.

## 8.6 Target applications

The temporal extensions are intended for problems such as:

- multivariate forecasting;
- nonlinear system identification;
- anomaly detection;
- predictive maintenance;
- industrial process modeling;
- trajectory modeling;
- event and sequence prediction.

The main scientific question is whether the constrained algebraic interaction structure that is useful for static tensor-product spline coefficients can also provide a useful inductive bias for **dynamic systems with memory**.
